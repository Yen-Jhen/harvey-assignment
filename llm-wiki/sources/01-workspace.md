## 核心內容

- Harvey 是提供背景與工作流程的工作空間，不是自行訓練的模型，也不是可自行運作的多 Agent 協調系統。
- 背景依專案選讀；工作流程文件是任務模板，不構成自動操作許可。
- 使用者負責科學判斷、批准相關操作，以及最終檢查與解讀。
- 不同模型不會因為使用同一個 Git 儲存庫而自動共享對話或執行協作；文件可用於交接。
- 模型筆記可能錯誤或過時，需要以目前可核對的資料確認。
