# 來源摘要 05：獨立理論審查

- 原始來源：Harvey 的 `workflows/theory-review.md`。
- 本次 ingest：2026-11-15；依使用者確認，整理審查輸入、重新推導、結果分類、盲審及獨立驗證。
- 公開範圍：[審核後來源摘錄](../raw/05-theory-review-excerpts.md)；摘錄不是完整原文。

## 核心內容

- 明確提供主張、定義、單位、參數範圍、假設、推導及獨立基準。
- 審查者從假設重新推導，檢查量綱、極限、符號、正規化與遺漏項，提出可區分不同解釋的測試。
- 區分已確立的內容、近似及尚未驗證的事項；模型意見一致不構成獨立物理證據。
- 盲審需提供受限制的輸入，審查者完成並記錄第一輪後才分享先前的模型結論；[AI 系統架構](03-ai-system.md)另指出，僅將審查寫在不同檔案並不能保證隔離。
