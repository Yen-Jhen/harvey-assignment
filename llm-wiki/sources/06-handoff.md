# 來源摘要 06：任務交接流程

- 原始來源：Harvey 的 `handoffs/README.md`。
- 本次 ingest：2026-11-15；整理任務交接、審查模式、資訊隔離、使用者決定及驗證界線。
- 公開範圍：[審核後來源摘錄](../raw/06-handoff-excerpts.md)；摘錄不是完整原文。

## 核心內容

- 用精簡文件記錄任務範圍、假設、限制、審查及使用者決定；詳細背景以連結提供，不必複製。
- 一般審查可以看到其他審查與先前討論；盲審的第一輪只能使用受限制的資料。
- 若無法確認審查者只收到盲審資料，應記錄為一般審查並說明原因。分開檔案本身並不保證隔離。
- 使用者處理分歧，明確批准後才進行正式研究程式修改，並負責執行科學分析及驗證結果。
- 交接文件不取代實際檢查與科學驗證。
