# Harvey LLM Wiki

這是以 Harvey 研究助理架構為主題的知識庫。**目前已 ingest 6 份來源**；其他資料將逐份討論、確認後處理。

## 主題

- [Harvey 的定位](topics/harvey.md)：工作空間的用途與邊界。
- [記憶與資料選讀](topics/memory.md)：背景資料如何保存與選讀。
- [Agent 與使用者](topics/agent-user.md)：協助、批准與最終判斷的分工。
- [Agent 工作流程與回饋](topics/agent-workflow.md)：任務、判斷、回饋、批准與交回。
- [跨模型交接](topics/model-handoff.md)：文件與 Git 在不同工具之間的作用與限制。
- [資訊可信度](topics/information-trust.md)：區分現行資料、歷史摘要與 AI 推論。
- [操作權限](topics/permissions.md)：修改前批准與分析執行的界線。
- [系統改善](topics/system-improvement.md)：以需求、驗收與評估驅動有界改善。
- [研究驗證流程](topics/research-validation.md)：釐清假設、唯讀檢視、授權與獨立驗證。
- [獨立理論審查](topics/theory-review.md)：從假設重新推導，並處理盲審的資訊隔離。
