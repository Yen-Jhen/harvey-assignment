# Harvey LLM Wiki 維護規則

## 範圍

此 Wiki 以 Harvey 的研究助理架構與工作流程為主。允許經使用者確認的一般物理研究背景；排除使用者指定的研究內容、真實研究程式及針對個別程式的具體要求。通用的工作範圍與授權原則可以保留。公開或分享前，仍由使用者審核內容。

## Ingest

1. 逐份與使用者討論來源，確認哪些內容可納入；未確認的來源不得擅自 ingest。
2. 讀取原始來源，但不修改原始文件。若在作業資料夾內保存去敏感化摘錄，標明它不是完整原文、記錄來源和日期。
3. 建立或更新來源摘要，區分來源明示內容與整理後的推論。
4. 更新相關主題頁及相互連結，標明來源；如新來源與舊資料衝突或時效不明，明確記錄，不自行猜測。
5. 更新 [索引](index.md)，並將本次 ingest 追加至 [日誌](log.md)。
6. 更新 HTML 瀏覽頁，使其與已確認的 Markdown Wiki 一致；尚未 ingest 的來源不得算入完成數。

## 查詢與檢查

- 回答問題時先參考索引，再讀相關主題及來源，清楚標示依據。
- 檢查斷鏈、缺少來源的主張、過時資料與主題之間的矛盾。
- Wiki 不提供對真實研究程式的操作權限；正式研究工作仍依 Harvey 的現行規則與使用者授權處理。
