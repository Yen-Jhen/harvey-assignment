# 記憶與資料選讀

Harvey 將可重用的背景與工作流程寫在文件中。Agent 處理專案任務時，選讀與當前問題相關的資料；不應把流程模板視為自動執行操作的許可。

AI 系統架構進一步建議以 Markdown 和 Git 歷史保存背景，而不是只依賴聊天；角色指示應保持精簡並按需要載入背景。

文件中的筆記可能錯誤或過時，因此仍需要與可核對的當前資料比較；有日期的紀錄互相衝突時，應指出差異，而非自行猜測。
